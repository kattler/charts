# rocattle charts

Helm charts maintained by rocattle, distributed as OCI artifacts on `ghcr.io/rocattle/charts`.

| Chart | Description |
| --- | --- |
| [oxynote](charts/oxynote) | Oxynote, an open-source technical wiki connected to the systems it describes |

## Usage

```console
crane ls ghcr.io/rocattle/charts/oxynote
helm install oxynote oci://ghcr.io/rocattle/charts/oxynote --version 0.1.0
```

`helm search repo` does not work with OCI registries. Use [crane](https://github.com/google/go-containerregistry/blob/main/cmd/crane/README.md) to list versions.

## Releases

A push to `main` that changes `version` in a `charts/*/Chart.yaml` packages that chart and pushes it to `oci://ghcr.io/rocattle/charts`. A version that is already published is skipped. To re-publish the same version, run the Release workflow manually with `force` enabled.

## Development

Chart `README.md` files are generated by [helm-docs](https://github.com/norwoodj/helm-docs) from `values.yaml` comments and `README.md.gotmpl`:

```console
helm-docs --chart-search-root charts --template-files README.md.gotmpl --sort-values-order file
```

Every chart ships a `values.schema.json`, updated together with `values.yaml`.
