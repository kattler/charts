Helm charts maintained by kattler, distributed as OCI artifacts on `ghcr.io/kattler/charts`.

| Chart | Description |
| --- | --- |
| [kubernetes-admission-policies](charts/kubernetes-admission-policies) | Kubernetes-native admission policies using ValidatingAdmissionPolicy and MutatingAdmissionPolicy with their policy bindings |
| [oxynote](charts/oxynote) | Oxynote, an open-source technical wiki connected to the systems it describes |

## Usage

```console
crane ls ghcr.io/kattler/charts/oxynote
helm install oxynote oci://ghcr.io/kattler/charts/oxynote --version 0.1.0
```

`helm search repo` does not work with OCI registries. Use [crane](https://github.com/google/go-containerregistry/blob/main/cmd/crane/README.md) to list versions.

## Releases

A push to `main` that changes `version` in a `charts/*/Chart.yaml` packages that chart and pushes it to `oci://ghcr.io/kattler/charts`. A version that is already published is skipped. To re-publish the same version, run the Release workflow manually with `force` enabled.

## Development

Chart `README.md` files are generated by [helm-docs](https://github.com/norwoodj/helm-docs) from `values.yaml` comments and `README.md.gotmpl`. Install the [pre-commit](https://pre-commit.com/) hook once and every commit regenerates them:

```console
pre-commit install
```

Run it manually across all charts with `pre-commit run --all-files`.

Every chart ships a `values.schema.json`, updated together with `values.yaml`.
